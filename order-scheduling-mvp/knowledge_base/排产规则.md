# 排产规则（V3.2）

日计划以一天一版为基准，每日上午由生产计划员编制并发布。班组只执行唯一生效版本，旧版计划在新版发布时自动作废，不得两版同时在现场流转。

插单处理：插单须先发起变更单，经审批同意后方可调整当日计划。插单占用的资源在审批期间予以冻结，不得分配给其他订单。变更版本必须注明被挤掉的原订单号，并保留原计划版本备查。

缺料处理：物料未齐套的订单不得排入当日计划。计划员应在排产前核对库存与在途物料，缺料订单标记为待料状态，待齐套后重新排入。

换型管理：换型时间须如实记录到系统中，作为排产依据。同规格产品应优先合批生产，以减少换型次数。

排产优先级：准时交付率第一，换型次数第二，设备利用率第三。重排时不得违反已冻结的工单安排。
