# 订单排产与设备异常智能体系统 — 量化测试方案

> 版本：v1.0　编制日期：2026-11-07　被测对象：`order-scheduling-agent`（FastAPI + SQLite MVP）
>
> 本方案覆盖 **正常、边界、对抗、权限、故障** 五大场景，共 **40 条量化测试用例**。每条用例均给出：用例编号、场景分类、前置条件、测试步骤、输入、预期结果、量化判定标准（通过阈值）与优先级。所有判定均可自动断言，适用于 pytest / unittest 自动化回归。

## 八、执行建议

1. **自动化优先**：建议将本方案 40 条用例全部脚本化，接入 pytest / unittest，纳入 CI 回归。现有 `tests/` 下 25 项单元测试可复用，本方案在此基础上补齐接口级与场景级用例。
2. **执行顺序**：正常 → 边界 → 权限 → 对抗 → 故障，先打通主链路，再逐层加压。
3. **环境隔离**：对抗与故障用例建议使用独立测试库（`DB_PATH` 指向临时文件），避免污染演示数据。
4. **量化断言**：每条用例的"量化判定"列可直接转换为代码断言（如 `assert resp.status_code == 200`、`assert body["status"] == "AWAITING_CONFIRMATION"`）。
5. **缺陷分级**：P0 用例失败即阻断发布；P1 失败需修复后回归；P2 可评估后延后。
